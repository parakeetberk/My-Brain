# Superseded lot sheets

These 56 files were generated in the first pass on 2026-08-31, before the lot parser knew the difference between a lot number and a description.

They came from source lines where the "lot" column held something that is not a lot: a count ("11 homes"), a group ("5, 16, 18, 33, 78"), a place ("the pond", "the clubhouse", "Green Oak"), or a piece of infrastructure ("lift station"). The second pass split the real multi-lot lists into individual lot sheets and dropped the rest, so every item in here is still filed. It lives on the community page's Pulse block, in [[60-Communities/open-items]] and in [[60-Communities/activity/2026-08-stream]].
