# Template version

**AI Brain Template v1.2.0** — Kit Starter Vault edition.

The 13-folder core in this vault is the same structure used in every AI Brain we build. The core never changes; your business lives in the subfolders. When the template improves, the changes are announced in the Kit — upgrades are deliberate, never automatic.

## Changelog
- **v1.2.0 — 2026-08-21.** The understanding-first Structure Interview. The old interview hunted for problems and starved half the folders; a vault built from it was sparse — thin CLAUDE.md, empty graph. Rebuilt: 7 parts mapped to the folder clusters they feed, ~35–40 questions; pain compressed into the final part only. New ground: identity (name, locations, countries served and whether delivery differs), online presence with an offered read-through of the website and profiles ("confirm instead of ask"), an offer loop that keeps asking until "that's it", competitors + differentiation in the owner's words, top customers by name, departments and who works in each (departments name the subfolders), a vendor loop with criticality, a tools loop, money flow and payment terms. A coverage check before Step 3 forbids proposing pages that can't be written. New mapped pages: `10-Business/competitors.md`, `vendors/`, `tools-and-systems.md`, `locations/`, `20-Brand-Marketing/voice.md`, `20-Brand-Marketing/online-presence.md`, `50-Products-Sales/pipeline.md`, `80-Finance/money-flow.md`. `CLAUDE.md` gains a full Who-we-are identity block. (Version jumps from 1.0.5 to join the shared template line — the reference implementation sits at v1.1.0.)
- **v1.0.5 — 2026-08-20.** Graph shape tuned against the reference implementation, measured: the Sahni.ai brain runs 899 nodes on only 349 edges (0.39 per node), two-thirds of them MOC→file, with 71% of files unlinked. So: MOCs link everything they own and are the hubs; **pages carry two links or fewer** (one or two real sources, at most one Related, never the ledger/index/siblings); the index lists MOCs and headline pages only, not every page; bulk raw material is filed and named but not linked; per-page tags dropped.
- **v1.0.4 — 2026-08-20.** MOC stars, measured from the reference implementation (Sahni.ai brain: MOC-Marketing 106 links, MOC-Products 67): every MOC links every file its folder owns; bulk dumps get a per-subfolder hub page (MOC → hub → files) so a 50-file dump reads as one mid-size star. Pages keep v1.0.3's tree rules (Sources 1–3, Related ≤2, no routine sibling/ledger links, one type tag).
- **v1.0.3 — 2026-08-20.** Graph shape: link like a tree, not a mesh. MOCs and the index wikilink pages only (raw files named, unlinked); a raw file gets on the graph when a page's Sources cite it (1–3 per page); Related capped at two earned links; no routine links to ledger/business-model/siblings; exactly one `tags:` type entry per page. Replaces v1.0.2's link-everything rules, which produced an unreadable mesh.
- **v1.0.2 — 2026-08-20.** Graph View density: every MOC Files list and every index row is a `[[wikilink]]` (attachments included); every page carries frontmatter `tags:` and links its Sources as `[[wikilinks]]`; the Structure Interview also writes one page per key account, per person, per SOP and per transcript; Page Update lists the durable-topic checklist. Skills touched: structure-interview, page-update, index-rebuild, transcript-filing; plus `_example-page.md`, every `MOC-*.md`, `00-Meta/index.md`, `CLAUDE.md`.
- v1.0.1 — 2026-08-15. Kit Starter Vault rebuilt on the 13-folder core.
