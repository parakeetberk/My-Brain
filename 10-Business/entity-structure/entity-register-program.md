# Entity Register program

**What this is:** the project page for building one evidence backed register of every entity since A2Z was formed in 2013, and the dynamic org chart that runs off it. Read this before any entity, formation document, signatory, registered agent or org chart work.

**Status:** current as of 2026-10-03 morning. Pass 1 (Bedrock) and pass 2 (A2Z, Parakeet platform, JREFI, JREFII, Origins, MA portfolio, Kippy) are both done. One company wide chart is live. Findings are collapsed into an 8 workstream cure program waiting on Austin's calls.

## The goal, in Austin's words

One dynamic org chart that tracks every entity since A2Z was formed in 2013, built from the LLC and formation documents (opened and read, not file names), showing who the partners and signers are, with every entity's documents organized, on file and signed. Do it once so it never has to be repeated.

## How it works

- **The chart is an output, not a drawing.** Under it sits a register: one row per entity, one row per ownership link, and every link points to the signed document that proves it.
- **Method per family:** inventory every source, open and abstract the best executed copy of each document, then a second reviewer re-opens every cited document and tries to refute each fact. Anything unread is labeled filename_only or hypothesis.
- **Sweep internal sources first, go external last.** CPAs and registered agents only after the internal sweep.
