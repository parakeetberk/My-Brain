It is the single source of truth for the configuration. Use it to build, QA, and train staff on the system. Version 1.2 incorporates the actual 89-item Construction Installation Checklist and 71-item Ops & Sales Readiness Checklist submitted by the field teams, expands the workflow to 12 stages, and establishes the system-wide Cascading Dropdown Architecture (Section 3A) as the standard for all Community → Lot → Asset selections across every Quickbase and FastField form. Rent Manager (RM) remains the system of record for asset records and financial data — this build complements RM, it does not replace it. Every form in Quickbase and FastField that includes Community, Lot, or Asset selection MUST follow these rules. This applies to all 15+ forms system-wide, not just Workflow #001. The Hierarchy Community └── Lot (filtered by Community) └── Asset (filtered by Lot + Asset Status) Each tier is a relationship field (never free-text). Selecting a value at one tier immediately narrows the options at the next tier. Community is always unfiltered. Lot is always filtered to the selected Community, then further filtered by Lot Status based on form context. Asset is always filtered to the selected Lot, then further filtered by Asset Status based on form context. Context-Specific Filter Rules — All Forms This table is the authoritative reference. When building any form, find the form in this table and apply the filter exactly as specified. The Lot list re-filters dynamically based on the Move In vs. Move Out selection. Get this wrong and incorrect lots are presented to users. Step 1: User selects Community → all lots in that Community load. Step 2: User selects Move In or Move Out → Lot list immediately re-filters: Selection Lot Filter Applied Asset Filter Move In Lot Status = Available (vacant lots only) If "Community Owned Home Sale?" = YES → show listed assets on Lot. If NO → no asset field shown Move Out Lot Status = Occupied (occupied lots only) Assets on selected Lot (the home being vacated) Why this matters: Without this filter, a Move In form could accidentally select an already-occupied lot. Without it on Move Out, it could target a vacant lot that has no one to move out. The filter eliminates those errors at the data entry point — not after the fact in a report. These automations keep it accurate automatically. Rent Manager is the authoritative system of record for all asset identifiers, resident accounts, lease data, and financial ledgers. Quickbase is the operational workflow layer — it orchestrates checklist progression, status tracking, and role-based approvals. FastField is the mobile field-capture layer for construction and operations inspections. No system replaces another; data flows in one direction per boundary and is never dual-entered. 7.1 Rent Manager → Quickbase (Master Reference Sync) Rent Manager is not replaced by Quickbase. It remains the canonical source for community names, lot identifiers, unit addresses, and lease records. Quickbase references Rent Manager IDs — it does not replicate financials or lease contracts.
