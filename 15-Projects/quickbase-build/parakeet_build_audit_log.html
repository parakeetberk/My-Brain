Section 02 Formatting & Data Standards
CRITICAL — These standards apply everywhere in this build: Quickbase field formats, FastField form fields, Excel deliverables, and all other outputs. No exceptions.

Percentages 1 decimal place 12.5% Never 12% or 12.50%
Dollar Amounts / Currency $ prefix, comma separator, 2 decimal places $1,234.56 Never $1234.56 or $1,234
All Other Numbers Comma separator, 2 decimal places 1,234.56 Exception: counts/IDs are whole numbers — no decimals

Field Naming Conventions (Quickbase)

  • Use Title Case for all field names
  • No abbreviations unless universally understood (e.g., "A/C", "VIN", "HVAC")
  • Boolean/checkbox fields: phrase as a confirmable statement — e.g., "Serial Number Confirmed" not "Serial Number Status"
  • Date fields: include the event name + "Date" — e.g., "Delivery Date", "Listing Date", "Set Date"
  • Cross-reference fields: use "RM" prefix for Rent Manager cross-references — e.g., "RM Asset Record #", "RM Unit #"

FastField Form Naming Convention

Pattern: PARAKEET — [WORKFLOW #] — [Form Name]

Examples:
PARAKEET — WF001 — Home Delivery Confirmation
PARAKEET — WF001 — Construction Inspection
PARAKEET — WF001 — Ops & Sales Readiness
PARAKEET — WF001 — Listing Form

Document Naming Convention

Pattern: parakeet_[descriptor]_[type]_v[version].[ext]

Examples:
parakeet_home_ordering_build_spec_v1.1.pdf
parakeet_jotform_audit_v1.0.xlsx
parakeet_build_audit_log_v1.0.pdf

Stage / Status Values

  • Always use Title Case (e.g., "In Production" — not "in production" or "IN PRODUCTION")
  • Never abbreviate stage names in QB. Spell out fully — it is a dropdown, length does not matter.
Section 10 Integration & Technical Notes

Quickbase ↔ FastField

  • Integration method: webhook-based JSON POST on FastField form submission (preferred)
  • Fallback: manual CSV export from FastField → QB import (acceptable for initial launch)
  • Matching key: Home Order # field appears on all FastField forms — used to link child records back to the master Home Orders table
  • All FastField forms prefixed PARAKEET — WF001 — [Name] for easy filtering within FastField admin

Quickbase ↔ Rent Manager

  • No automatic sync. QB and RM are parallel systems.
  • Cross-reference fields (RM Asset Record #, RM Unit #) are manually maintained by Asset Mgmt
  • QB does not create or modify RM records — it tracks workflow state only
  • Asset Mgmt (Justin) is responsible for keeping both systems updated when QB stage changes require RM updates

File Storage

  • FastField photo/video attachments: stored in FastField, linked back to QB child records
  • Order documents: stored in Teams/SharePoint in temporary folder per batch (per SOP Step 5)
  • Signed invoices / loan docs / insurance: uploaded to Rent Manager (per SOP)
  • PSA uploads (from Offer form): decision pending — see Q-003
