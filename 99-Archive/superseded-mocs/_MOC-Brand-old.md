# MOC — Brand

How Parakeet sounds and looks. The visual side is automated by the `parakeet-brand` skill, so this folder is mostly about voice.

## Files in this folder

- [[20-Brand-Marketing/voice]] — one voice, Austin's, adapted per audience. The habits, the register shifts, and the vocabulary. **No em dashes, ever.**
- `voice-samples/` — empty as of 2026-08-30. The best samples currently live elsewhere in the vault: the Employee Handbook welcome letter and core values for resident-facing warmth, the Bedrock partner letters for investor tone, and [[70-Operations/sops/200-demo-and-lot-prep]] for the internal imperative register.

**Not in this folder, on purpose:** colours, typography and logo rules. Those live in the `parakeet-brand` skill and are applied automatically to every file deliverable. Duplicating them here would create two sources of truth.
