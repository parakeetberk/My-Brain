# Inbox — the drop zone

Drop ANYTHING new here: meeting transcripts, PDFs, screenshots, spreadsheets, half-written ideas, that email you want the Brain to know about. Don't organise it — that's Claude's job.

**Claude's ingest rule:** for each item — read it, push the durable facts onto the right pages (numbers go to `00-Meta/numbers-ledger.md` with a source), file the item into the folder that owns it, add a line to `00-Meta/log.md`, and leave the Inbox empty. Anything Claude isn't sure about stays here with a note in `_needs-sorting.md` — flagged, never guessed.
